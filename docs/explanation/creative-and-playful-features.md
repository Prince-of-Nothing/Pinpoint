# Creative and Playful Features

These are deferred, Full-mode features layered on top of the safety-first
MVP. They remain separate from location permissions and can be added after
the safety foundation is reliable.

## Daily prompts

A shared prompt can invite users to submit a photo, writing, code, audio,
video, or another response. Discovery, lightweight ratings, attribution,
accessibility, content notes, and moderation are optional later layers. See
[Daily Prompts and Media](./daily-prompts-and-media.md).

## Playful experiments

The app may host temporary challenges, friend activities, scavenger hunts,
collaborative prompts, and other lightweight games. Coding belongs as one
ordinary prompt category alongside writing, drawing, audio, video,
photography, and other media.

These features remain separate from location permissions and can be added
after the safety foundation is reliable.
