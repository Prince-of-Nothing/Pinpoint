# UI Navigation and Wireframes

## Primary navigation

Map, Friends, Chats, Discover, and Profile. Lite mode can hide community
areas without removing account and privacy controls.

## Key screens

- active sharing map with freshness and stop-sharing control;
- friend and consent management;
- cache creation and permission preview;
- navigation choice: in-app route or external map;
- chat and group safety controls;
- prompt gallery and submission flow;
- challenge creation, invitation, participant roster, submission deadline,
  scoreboard, and results thread;
- reports, blocks, moderation notices, and account privacy settings.

Location status should never be hidden behind a social feed or ambiguous
icon.
