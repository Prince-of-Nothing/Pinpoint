## Writing Principles

See the [Diátaxis tutorials guide](https://diataxis.fr/tutorials/) for writing principles:
- Concrete steps with guaranteed outcomes
- Minimal explanation (save "why" for [explanation/](../explanation))
- Focus on building confidence
- Write for following along, not lookup
