# Daily Prompts and Media

A prompt has a title, description, deadline, categories, accessibility
notes, content warnings, and moderation status. Users may submit writing,
images, code, audio, or video.

The gallery can support pseudonyms, attribution, ratings, comments,
discovery, and creator controls. Prompt suggestions may be grouped for
duplicates, but automation recommends rather than silently rejects. Media
requires size limits, malware scanning, reporting, takedown, and retention
rules.

Global prompts can be attached to a selected group chat, creator group, or
public event. The prompt remains global in origin, while the chat defines
the invited participant list, conversation, deadline, and results. A user
should always know who can see their submission before posting.

## Suggestion and selection system

Users may submit prompt suggestions in any supported medium, including
coding. The system first applies rate limits, AI safety screening, metadata
normalization, and similarity indexing. Near-duplicate suggestions are
grouped into clusters so repeated wording does not dominate selection.

Each eligible suggestion or cluster receives a transparent selection weight
based on factors such as freshness, category balance, accessibility, prior
use, community support, and editorial status. The weekly or daily community
prompt is selected by weighted random choice from the eligible pool. Random
selection is auditable and does not guarantee popularity wins.

AI is a screening and organization tool, not the final authority. Human
review handles ambiguous safety cases, appeals, and all sponsored
suggestions. See
[Prompt Selection and Sponsorship](./prompt-selection-and-sponsorship.md).
